# USDT Rate Service

Этот сервис предназначен для получения курса USDT в USD с биржи Exmo.

## Установка и запуск

### 1.Клонирование репозитория

```
git clone https://studentgit.kata.academy/tebtyc/usdt-rate-service.git
cd usdt-rate-service
cp .env.example .env
```

### 2.Запуск в Docker
Для того чтобы создать и запустить контейнеры приложения и базы данных, используйте команду:

```
make up
```

Чтобы остановить контейрнеры, выполните:

```
make down
```

### 3.Локальный запуск

Для локального запуска приложения:

```
make build
./usdt-rate-service
```

**Примечание:** Перед этим убедитесь, что PostgreSQL запущен.

# API(gRPC)

### Доступные методы:

- GetRates - получение курса USDT.
- Check - Проверка состояния сервиса.

# Разработка и тестирование 

### 1. Доступный список Make команд 

Для получения списка всех доступных команд в Makefile выполните:

```
make help
```

### 2. Запуск миграций

Чтобы выполнить миграции, сначала укажи путь к миграциям и парметры подключения к базе данных, используя флаги.

Параметры миграции
- -db-host - хост базы данных (по умолчанию localhost).
- -db-port - порт базы данных (по умолчанию 5432).
- -db-user - имя пользователя для подключения к базе данных.
- -db-password - пароль для подключения к базе данных.
- -db-name - имя базы данных.
- -migrations-path - путь к папке с миграциями (обязателен).
- -down - откатить последнюю миграцию (если нужно откатить изменения).

Пример запуска миграций:

```
 go run cmd/migrate/main.go -db_host=localhost db_port=5432 db_user=postgres db_password=secret db_name=usdt_rate_db migration_path=migrations
```
